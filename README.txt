BUTKI ❤️ — Birthday Website

The uploaded audio track is bundled as song.mp3.
To play it, open the website and tap the ▶ button at the top-right.
Browsers generally block autoplay until the visitor interacts with the page.

To preview: open index.html in a browser.
To publish with GitHub Pages: upload index.html, song.mp3, and the assets folder
to a public GitHub repository. Then Settings → Pages → Deploy from a branch →
main → /(root) → Save.

The song file is included exactly as uploaded.
